# KODVIT website

## Goal

Create a polished, responsive KODVIT website using the supplied logo and its blue, light-blue, orange, white, and navy palette. Keep Trinetra Tech clearly separate, show only verified facts, and use labelled gallery placeholders until real event photos are provided.

## Pages and experience

- Build a homepage with company introduction, software services, NFC digital cards, Trinetra Tech and its 200+ student achievement, gallery previews, process, and contact calls to action.
- Add separate About, Software Solutions, Digital Products, Trinetra Tech, Gallery, and Contact pages with working navigation and page-specific metadata.
- Include mobile navigation, responsive branded styling, subtle reduced-motion-friendly animation, and an accessible gallery viewer.
- Preserve the logo as supplied and create the matching browser icon.

## Contact enquiries

- Save validated contact submissions in Lovable Cloud with row-level protections; do not show a false delivery confirmation.
- Use the confirmed recipient address for email notifications only after the project has a verified sending domain. Email sending is currently unavailable, so submissions will be stored until email setup is completed.

## Technical details

- Use the existing TanStack Start routing and Tailwind v4 design tokens; add shared site navigation/footer components and page files.
- Add a public contact-submissions table with explicit grants, RLS, and a server-side validated submission handler.
- Verify route rendering, form persistence where possible, and current preview/build health.
